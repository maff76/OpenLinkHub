OpenLinkHub v12.4.74z7d9i - effect + profile mapping audit fixes

Baseline: current z7d9h behaviour plus today's renderer/topology/editor work.
Changed complete files only; no patch/diff files.

Confirmed audit fixes:
1. DRAM compatibility canvas selection now uses the installed RGB DIMM layout.
   The previous global "smallest DramSoftware canvas" rule could choose a one-DIMM
   or wrong-LED-count compatibility entry. Runtime now chooses the smallest canvas
   that covers moduleCount * ledCount and prefers an exact physical LED stride.
2. RenderDRAM receives the actual RGB module count from memory.go, so two 6-LED
   DIMMs resolve against a canvas that can represent at least 12 logical LEDs.
3. Editor colours now consume Go-decoded sourceColors first. This supports packed
   first=/second= Corsair ARGB values used by Rain/Wave/ColorWave instead of showing
   black/missing colours when the browser cannot parse those leaves itself.
4. Compatibility reporting is synchronized with renderer support for Breathe,
   Ripple, Spiral, Visor, Marquee and Sequential.
